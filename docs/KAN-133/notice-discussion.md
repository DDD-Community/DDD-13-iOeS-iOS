# 공지사항 화면 — 팀 논의 포인트 (KAN-133)

## 1. pinned 공지 시각 강조
- **현재 구현**: 서버가 "고정 공지 최신순 상단" 정렬을 보장 → 클라는 응답 순서 그대로 렌더. `pinned` 필드는 모델에 보관하지만 **시각적 강조/배지는 없음**.
- **배경**: Figma 시안에서 첫 항목만 흰색, 나머지는 회색으로 보이나, 이게 (a) pinned 강조인지 (b) 읽음/안읽음 표시인지 (c) 단순 시안 노이즈인지 불명확.
- **결정 필요**: pinned 항목에 별도 배지("공지")/배경/아이콘이 필요한가? 필요 시 디자인 토큰 + 컴포넌트 후속 합의.

## 2. 본문 렌더 포맷
- **현재 구현**: plain text + `\n` 줄바꿈 유지 + `lineSpacing`. 마크다운/HTML/링크 파싱 없음.
- **결정 필요**: 서버가 추후 리치 텍스트(HTML/마크다운/이미지 첨부)를 내려줄 계획이 있는가? 있다면 렌더 전략(AttributedString / WebView 등) 합의 필요.

## 3. 읽음/안읽음 · 신규 뱃지 · 새로고침
- **현재 범위 밖**: 읽음 상태 표시, 마이 탭 "공지사항" 셀의 신규 공지 뱃지, pull-to-refresh.
- **결정 필요**: 사용자 기대치 대비 우선순위. 필요 시 별도 티켓 분리 권장.

## 4. 빈/실패 문구
- **현재 구현**: 빈 목록 "등록된 공지사항이 없어요", 로드 실패 "공지사항을 불러오지 못했어요" + 다시 시도.
- **결정 필요**: 카피 확정(디자인/기획 검토).
