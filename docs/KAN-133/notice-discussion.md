## 1-2. 목록 본문 미리보기 1줄 — **API 의존성 (블로커)**
- **스펙(추가)**: 목록 row에 제목 아래 본문 미리보기 1줄 고정 노출(말줄임), 전체 공지 동일 적용.
- **현재 구현**: `NoticeListItem.content: String?`를 옵셔널로 두고, 값이 있으면 1줄(gray30, 말줄임) 렌더 / 없으면 줄 생략. UI는 완료.
- **블로커**: 목록 API(`GET /v1/bbs/posts`) 응답 샘플엔 `content`(본문) 필드가 없음 → 현 상태로는 미리보기가 항상 비어 생략됨.
- **결정 필요**: 목록 응답 items에 `content`(또는 `summary`/`preview`) 필드를 추가할지 + 필드명/길이 정책(서버가 N자 잘라 내려줄지, 전체 본문을 주고 클라가 1줄 자를지). 합의되면 모델 디코딩 키만 맞추면 됨(이미 옵셔널이라 추가 코드 거의 없음).
