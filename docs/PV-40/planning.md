# [기획] 유저 스팟 공개 시스템 (오픈·출처표기·추천) — PV-40

> 작성: 김예은 / Figma: https://www.figma.com/design/WLGPjrQtLqyhq46zXxvXHp/DDD-design-%EC%B0%90?node-id=686-7273
> 스팟 검수(승인/반려) 어드민 정책·상태 정의는 별도 문서(스팟 검수용 어드민 페이지, Next.js) 기준.
> 이 문서는 검수 결과가 **유저 앱 화면에 어떻게 보이는지**만 다룸.

## 1. 맥락
- V1의 "MY 스팟"은 본인만 보는 비공개 아카이빙. 현재 상세페이지 "내 스팟 오픈하기"는 "업데이트 소식 받기" 웨이팅 팝업만 노출.
- V2에서 정식 기능으로 확장. 관리자 큐레이션 중심 지도를 유저와 함께 만드는 지도로 확장.
- **검수 시점**: 등록은 검수 없이 즉시 나만보기. **"오픈하기"를 누르는 시점부터 검수 시작**(서버팀 협의 확정). 즉 신청 → 검수 → 승인 시 공개.

## 2. 범위
### In Scope
- 오픈 신청 / 신청 철회 / 오픈 취소 (나만보기 ↔ 검수중 ↔ 오픈)
- 오픈 신청 확인 모달 / 접수 토스트
- 반려 사유 배너 + "내용 보완해서 다시 신청하기"
- 오픈 취소 확인 모달 (승인·공개 상태에서 스스로 비공개 전환, 검수 정책과 무관한 별도 메커니즘)
- 모든 스팟 카드(큐레이션 포함) 출처 표기 줄 고정 노출
- 지도 핀 색상으로 큐레이션 vs 유저오픈 구분
- 추천 등록/취소 (큐레이션·유저오픈 공통, 셀프 추천 허용 — 공개된 스팟만)
- 오픈 취소 후 재오픈 시 기존 좋아요 수 유지
- 북마크한 유저오픈 스팟 비공개 전환 시 보관함에서 삭제 대신 상태 표시
- 유저오픈 스팟에 기존 "잘못된 정보가 있나요?" 피드백 링크 재사용
- 유저 등록 스팟 삭제 기능 (수정은 Out of Scope, 반려 후 재신청 시 수정만 예외)
- 오픈 검수 결과 안내 (스낵바 + 저장 아이콘 인디케이터 + 상세페이지 첫 진입 모달)

### Out of Scope (V2 이후)
- 신규 오픈 스팟 "NEW" 뱃지 등 시각 신호
- 큐레이션-유저오픈 위치 중복 그룹화/클러스터링 기준 조정
- 좋아요 전용 모음 목록 화면
- 좋아요 알림, 팔로우/작성자 프로필, 노출 랭킹·정렬 고도화
- 어드민 승인/반려 정책·검수 기준·어드민 화면
- 스팟 수정 기능 (반려 후 재신청 시 제외)

## 3. 상태 / 인터랙션
### 3.1 상태 모델
| 구분 | 값 |
| --- | --- |
| 출처 | 관리자 큐레이션 / 유저 등록 |
| 공개상태 (유저 등록 스팟만) | 나만보기(기본값) → 검수중 → 승인 / 반려 |

- 등록 직후: 검수 없이 즉시 **나만보기**
- "오픈하기" 신청: **검수중** (어드민과 동일 표현)
- 승인: 지도/리스트 노출 시작
- 반려: 나만보기로 남되 반려 사유가 상세페이지 배너로 표시
- 반려 후 재신청: 다시 검수중 (어드민 기준 "재검토 대기 중")
- 관리자 큐레이션 스팟은 처음부터 오픈 상태이며 이 전환과 무관

### 3.2 오픈 신청 플로우
1. 나만보기 상세페이지에서 "내 스팟 오픈하기" 탭
2. 확인 모달
   - 제목: "스팟을 오픈하면 다른 유저들도 볼 수 있어요"
   - 본문: "간단한 확인 절차를 거친 후 지도에 공개돼요. 확인 전까지는 나만 볼 수 있어요."
   - 버튼: **오픈 신청하기** / 다음에요
3. 오픈 신청하기 → 검수중 전환 + 토스트 "오픈 신청이 접수되었어요"
4. 다음에요 → 모달만 닫힘, 상태 변경 없음
- 검수중은 지도/리스트 미노출 (본인 화면에서만 "검수중" 상태 확인)

### 3.3 검수중 및 신청 철회
- 검수중 상세페이지: "신청 철회하기" 버튼
- 철회 확인 모달
  - 제목: "신청을 철회할까요?"
  - 본문: "철회하면 나만 볼 수 있는 상태로 돌아가요. 언제든 다시 신청할 수 있어요."
  - 버튼: **신청 철회하기** / 계속 기다릴게요
- 확정 → 즉시 나만보기 / 계속 기다릴게요 → 모달만 닫힘
- **예외**: 철회 확정 시점에 검수자가 이미 승인/반려 확정 → "이미 처리된 신청이에요" 안내 후 최신 상태로 화면 갱신

### 3.4 승인 시
- 검수중 → 승인, 지도/리스트 즉시 노출
- 결과 안내
  - 지도/리스트 화면: 스낵바 (승인 "바로가기" → 오픈된 스팟 상세 / 반려 "확인하기" → 반려된 스팟 상세)
  - 하단 네비 "저장" 탭 아이콘: 검수 신청 중 인디케이터, 결과 확인 전까지 유지
  - 상세페이지: 승인 후 첫 진입 시 "스팟 오픈 완료" 모달

### 3.5 반려 및 재신청
- 검수중 → 반려, 나만보기 유지 + 반려 사유 저장
- 상세페이지 상단 반려 사유 배너, 버튼 2개: "오픈 철회하기" / "내용 보완해서 다시 신청하기"
- 재신청 탭 시 최초 등록 폼 재사용, 기존 입력값(사진/스팟명/주소/필터/코멘트) 프리필
- 제출 시 재신청 확인 모달
  - 제목: "다시 신청할까요?" / 본문: "제출하면 검수가 다시 시작돼요." / 버튼: 신청하기 / 계속 수정할게요
- 신청하기 → 검수중 전환 / 계속 수정할게요 → 모달만 닫힘, 폼 유지

### 3.6 오픈 취소 (공개 → 나만보기)
1. 공개 상태 상세페이지에서 "오픈 취소하기" 탭
2. 확인 모달: "취소하면 나만 볼 수 있는 상태로 돌아가요. 좋아요 수는 그대로 유지되고, 다시 오픈하면 이어서 보여요."
3. 확정 → 나만보기 전환, 타 유저 기준 지도/리스트에서 즉시 제거
4. 좋아요 수 등 메타데이터는 서버 보존 → 재오픈 승인 시 복원

### 3.7 화면별 표시 규칙
| 화면 | 나만보기 | 검수중 | 반려 | 승인 | 관리자 큐레이션 |
| --- | --- | --- | --- | --- | --- |
| 상세페이지 | "내 스팟 오픈하기" | "신청 철회하기" | 반려 사유 배너 + "내용 보완해서 다시 신청하기" | "오픈 취소하기" / 추천 버튼+카운트 / 피드백 링크 | 추천 버튼+카운트 / 피드백 링크 |
| 출처표기 | - | - | - | 스팟명 옆 "유저 등록" 뱃지 | "한국관광공사" / "Pickflow 운영자" 등 소스별 고정값 |
| 지도 핀 | 본인 화면에서만 회색 MY 핀, 클러스터링 대상 아님 | 노출 없음 | 노출 없음 | 기본은 일반 스팟과 동일, 선택 시 기존 주황 링, 공용 클러스터 풀 편입 | 기존 오렌지 핀, 클러스터링 유지 |
| 리스트 카드 | 본인 화면에서만 노출 | 노출 없음 | 노출 없음 | 출처 없음 (상세에서만 확인) | 출처 없음 (상세에서만 확인) |

### 3.8 추천 인터랙션
- 탭 → 카운트 +1, 활성 상태 / 재탭 → 취소, -1
- 셀프 추천 허용
- 공개된 스팟(오픈된 유저 스팟 + 큐레이션)에만 노출. 나만보기·검수중·반려는 버튼 없음
- 추천 전용 모음 화면 없음 (가고 싶다 = 북마크, 추천 = 가벼운 반응)
- 축약 표기(1천+) 없이 원 숫자 그대로

### 3.9 북마크 — 비공개 전환 대응
- 북마크 시점 사전 안내: "작성자가 언제든 비공개로 전환할 수 있어요"
- 오픈 취소 시 보관함에서 삭제하지 않고 흐릿한 "비공개로 전환됨" 상태 유지
- 탭 시 짧은 안내 + "목록에서 삭제" 버튼 하나만 (별도 "나중에" 없음, 바깥 탭/뒤로가기로 닫힘)

### 3.10 작성자 탈퇴
- 계정 정책(기한 내 재가입 시 복구)에 맞춰 탈퇴 시 스팟/좋아요 즉시 삭제하지 않음
- 저품질 스팟은 운영에서 개별 판단 삭제 (자동 로직 없음)

## 4. 인터랙션 예외
### 4.1 UI 레벨
- 확인 모달 "다음에요"/"취소" 시 상태 유지하고 닫힘
- 좋아요 연타 시 한 번만 반영 (중복 카운트 방지)
- 닉네임 미설정 유저 → 기존 형용사+명사 기본 닉네임
- 좋아요 수 축약 표기 제외

### 4.2 시스템 레벨
- 오픈 신청/철회/오픈취소 네트워크 실패 → "실패했어요, 다시 시도해주세요" 토스트, 화면은 이전 상태로 롤백
- 철회와 검수자 확정 동시 발생 → "이미 처리된 신청이에요" 안내 후 최신 상태 갱신
- 추천 실패 → 카운트/버튼 롤백 + "잠시 후 다시 시도해주세요" 토스트
- 동시 추천/취소 → 서버 최종 반영 숫자 기준으로 화면 재동기화
- 비로그인 추천 시도 → 로그인 유도 모달/화면 이동

- [ ] 오픈 취소 동작, 추천 수 유지

## 참고 — 유저 시나리오
1. **등록자 오픈 신청~승인**: 나만보기 스팟 → 오픈하기 → 확인 모달 → 신청 → 접수 토스트 → (본인만 "검수중" 확인) → 승인 → 지도/리스트 노출
2. **반려 후 재신청**: "선택하신 필터와 사진이 맞지 않는 것 같아요" 반려 → 배너로 사유 확인 → 재신청 탭 → 프리필 폼에서 사진 교체 후 재제출 → 검수중
3. **오픈 취소**: 추천 34개 받은 공개 스팟 → 오픈 취소 → "추천 수는 유지돼요" → 확정 → 비공개, 추천 수 서버 보존
4. **탐색자 발견**: 지도에서 유저오픈 스팟 발견 → "유저 등록" 뱃지로 출처 확인 → 추천은 가볍게, 가고 싶으면 북마크 → 북마크 시 비공개 전환 안내
5. **북마크 스팟 비공개 전환**: 보관함 재진입 시 흐릿한 "비공개로 전환됨" → 탭하면 안내 + "목록에서 삭제" → 삭제 안 하면 계속 상태표시 유지
